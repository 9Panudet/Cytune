# D7 — generator-v2 spec omitted `intended_class`; campaign.finalize crashed on fleet kernel #1

**Step:** P-2 synth stage, fleet kernel #1. **Date:** 2026-07-17. **Status:** fixed, validated.
**Commit:** 42fa922. **Raw:** traceback in `results/fleet/run_fleet.log` (KeyError at
campaign.py:332); the failed attempt's MEASURE_FAIL entry retained in
`results/fleet/fleet_ledger.jsonl` (run_id 20260716T224959Z) as honest history.

## Summary

The first fleet kernel (`fleet_FLAT_FM_06_fm_sum`) measured cleanly — 864/1728 feasible (the
trap_wrap FEAS design working as designed), endpoint agreement OK — then `campaign.finalize`
crashed reading `spec["intended_class"]`: generator v2's spec.json carried the v2 vocabulary
(`intended_regime`) but not the inherited pilot-schema key finalize requires. The runner
correctly ledgered MEASURE_FAIL and moved to a re-parameterized attempt, which would have failed
identically after another full measure cycle; the heartbeat caught the red event and stopped the
stage ~2 minutes into the wasted rebuild.

## Root cause

A schema-contract miss between new and inherited code: generator v2 defined its spec from the
A-2 vocabulary without checking every consumer of the pilot spec schema. The gen2 compile smoke
validated cythonize+gcc for every template but never drove a kernel through measure_phase, so
finalize — the LAST step of the measure container — was the first untested line the fleet hit.

## Fix

1. v2 specs mirror `intended_regime` into `intended_class` (finalize's contract; measured
   membership still rules per A-2i — the intended label is design intent only).
2. Resume completeness is now `class_record.json` presence (`_measure_complete`), not
   `endpoint.json`: the finalize-crash shape (table+endpoint, no class_record) triggers the
   B_05/C_04 delete+redo precedent instead of crashing classify_v2 downstream on the missing
   file. Both skip-container conditions updated.
3. Kernel #1's stale measure products were cleaned (build cache kept) and the bug-window `_r1`
   attempt dirs removed.

## Validation

Relaunched synth: kernel #1 auto-cleaned, re-measured fresh under a single calibrate context,
passed finalize, classified **v2=FLAT, FM=True, FEAS=True, boundary flags []** and was ACCEPTED —
the intended stratum, end-to-end. 11 harness tests green in X′ including the new
finalize-crash-shape test (`test_run_fleet.py`) and the spec-contract test (`test_generate_v2.py`).

## Why it slipped through / lesson

Same class as D6: a contract change (new producer, old consumer) validated only against the
producer's own tests. The smoke for a new generator must drive ONE kernel through the ENTIRE
consumer chain (build → measure → finalize → classify), not just the build half. Cost of the
miss: one wasted ~55-min measure + ~25-min rebuild window; caught before any further slots burned.
