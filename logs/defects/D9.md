# D9 — stencil template OOB by construction; RUN-smoke upgrade caught two more call-time bugs

**Step:** P-2 synth stage, MID slot 9 (`fleet_MID_09_mid_stencil`). **Date:** 2026-07-19.
**Status:** fixed, validated (smoke PASS incl. functional calls). **Raw:**
`results/fleet/run_fleet.log` — `IndexError: Out of bounds on buffer access (axis 0)` at
kernel.pyx:15 during calibrate's reference measure; MEASURE_FAIL in the fleet ledger.

## Summary

`_pyx_mid_stencil` iterated all `n` output elements while reading the forward window
`a[j+width−1]` from an equally-sized input — the last width−1 iterations read past the end, so
EVERY call failed (IndexError with bc=on at the reference; UB with bc=off) and the slot ledgered
MEASURE_FAIL after a full build. Same defect class as D7/D8: a producer-side contract never
exercised by the compile-only smoke.

## Fix + the systemic close-out

1. Stencil loop runs to `n − (width−1)` (tail of `out` stays zero — deterministic, oracle-safe;
   trap variant's `a[−1]` under wraparound remains the designed FEAS mechanism).
2. **`a2_gen2_smoke.py` upgraded per the D8 lesson: it now RUNS one untimed `measure_child` call
   per emitted template instance** (K=1, warmup=1, no oracle, no timing rows) after building it.
   The upgraded smoke immediately caught two MORE latent call-time bugs before any fleet cycle
   burned on them:
   - `mid_convert`: driver allocated the out array as int64 against the pyx's `double[::1]`
     (dtype ABI mismatch) → `_drv_int_map` gained an `out_dtype` parameter.
   - `lev_axpy`: the three-array pyx (`a, b, out`) was wired to the two-array `_drv_map` recipe
     (arity mismatch) → dedicated `_drv_axpy` builder.
3. Validation: full smoke = every template × {plain, FEAS variant} × build(cfg 288, 1506) +
   functional call(cfg 288) → **PASS**; 13 harness tests green in X′.

## Lesson (closes the D7→D8→D9 arc)

Three consecutive fleet defects were all producer/consumer contracts invisible to a build-only
smoke. The smoke now exercises the full chain to the first kernel call for every template
instance; remaining exposure is finalize-path-only bugs (D7's slice), covered by the spec-contract
test added there. Cost of D9: one wasted build+partial-measure cycle (~30 min), caught by the
heartbeat on the first failing slot.
