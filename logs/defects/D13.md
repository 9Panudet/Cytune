# D13 — the honest-flat route certified an "IMPROVEMENT" from a selection-biased probe minimum (self-contradictory certificate)

**Step:** P4-alpha CLI v0 (Amendment A-4), E2E smoke run 2. **Date:** 2026-07-25.
**Status:** fixed, validated (commit `7caa145`; composition-level E2E check green on current code
and RED on the reconstructed pre-fix path). **Raw:**
`results/cli_v0/ws/pilot_C_01/{certificate.json,table.jsonl}`. Recompute:
`python3 scripts/cytune_e2e_composition_check.py`.

## Summary

On the honest-flat route `cytune` skipped tuning — correctly — and then emitted an **IMPROVEMENT**
verdict anyway, built from the fastest of the 17 configs the *probe* had already measured. The
certificate therefore contained two contradictory statements about the same kernel: the routing
section said the landscape was flat and any apparent speedup was indistinguishable from noise, and
the verdict section claimed 1.031×. Fixed by making the flat route emit the reference
unconditionally and demoting the incidental probe minimum to a labelled, non-actionable
observation.

## Symptom

Smoke run 2 (`pilot_C_01`, a v1 class-A kernel with full-table `delta_all = 1.033`) produced:

```
[3/6] route
      rule R1 -> honest-flat
      probe spread 1.0983 <= 1.1 — at or below the noise floor, so any apparent speedup here is
      not distinguishable from measurement noise
[4/6] tune
      skipped — the probe says this landscape is flat.
...
VERDICT: IMPROVEMENT
  1.031x faster than the reference configuration, verified at the endpoint tier and re-checked
  against the oracle.
```

## Root cause

`src/cytune/cli.py` called `plan.select_winner(feas, ...)` unconditionally, where `feas` is
`session.feasible_medians()` — **every feasible row in `table.jsonl`**, which on the flat route is
exactly the 17 probe rows. `select_winner` (`src/cytune/plan.py`) does what its name says: it
returns `min(cands, key=...)`. It has no notion of *how* those rows got measured.

The route decision (`src/cytune/routing.py::route`, rule R1) governed only whether the **tune**
stage ran. It did not govern **winner selection**, so the two stages disagreed about what the run
had concluded.

## Why it produced the symptom

The minimum of B noisy measurements of an essentially flat landscape is biased low by selection
alone: with per-config log-noise sd `s`, `E[min of B]` sits `s·E[max_B Z]` below the truth. That
bias is what rule R1 exists to refuse. By selecting over the probe sample and then re-measuring
only the winner at the endpoint tier, the pipeline preserved enough of the bias to clear its own
1.02 emit floor — and the endpoint re-measure, being a genuine independent measurement of *that
config*, then made the number look verified. Every individual step was correct; the composition
converted a sample artefact into a claim.

## Fix

`src/cytune/cli.py`: on `route == HONEST_FLAT` the emitted config is `theta.REFERENCE_ID`, full
stop. The probe minimum is still measured at the endpoint tier — the user gets a real number — but
it is carried as `certificate.flat_observation` and rendered under `OBSERVED BUT NOT RECOMMENDED`
with an explicit statement that sample minima are biased low on flat landscapes.

This addresses the root cause rather than the symptom: the alternative (raising the emit floor
until 1.031× fell below it) would have left selection and routing still disagreeing, and would have
been a threshold tuned to one observed number. The floor was *separately* generalised — see D15 —
but that is a different defect.

## How it was found

Reading the first end-to-end smoke output line by line. No test caught it and no test could have:
`test_cytune_routing.py` asserts R1 fires on flat features (it does), and
`test_cytune_plan.py::test_select_winner_*` asserts `select_winner` returns the fastest feasible
config (it does). Both components were individually correct.

## Why it slipped through

**Unit-test gap at a composition seam.** The pipeline's stages were tested in isolation and no test
asserted a property of the *whole run's output*. The class of bug — "each part correct, the
composition dishonest" — is invisible to unit tests by construction.
